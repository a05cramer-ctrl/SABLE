04 · Developers

Build private banking before the day is out.

One lightweight, typed SDK wraps the REST API. A single client covers accounts, encrypted transfers, agent accounts with spend policies, and webhooks.

  1. Typed end to end, idempotent out of the boxEach create call takes an idempotency key, which makes retries safe when a process restarts.
  2. Webhooks worth relying onSettlements, policy hits and agent actions each arrive as signed events that one helper verifies.
  3. Separate test and live keys, no mode flagThe key prefix tells the client which environment to use, so there is no setting to get wrong.
Open the docs →Create an API key
quickstart.tsTypeScript · illustrative
import { Sable } from "@sable/sdk";

const bank = new Sable({ apiKey: process.env.SABLE_API_KEY });

// On-chain, the amount stays encrypted. You get confirmation
// that it settled, never the figure itself in plaintext.
const transfer = await bank.transfers.create({
  to: "@vendor",
  amount: "125.00",
  asset: "USDC",
  memo: "Invoice #4471",
});

// Spin up an agent with its own account and a strict budget.
const agent = await bank.agents.create({
  handle: "datafetch",
  policy: { dailyLimit: "50.00", maxPerRequest: "5.00" },
});

console.log(transfer.status, agent.address);

05 · FAQ

Plain answers to common questions.

Does Sable make me anonymous?

No. It keeps amounts and balances private. Handles and the fact that a transfer happened can still be seen, and your identity is verified once at sign-up.

Will I need to know how blockchains work?

No. You sign in with a passkey and send to an @handle. Keys, fees and proofs are handled for you.

What is an agent account, exactly?

A separate account with its own balance and its own spend policy, owned by you and operated by software. It can pay x402 requests on its own.

Could an agent overspend what I allowed?

No. The limits are checked by the program before a transaction is signed, and any overspend reverts.

How do I show a payment to an auditor?

Create a scoped view key for the transfers you choose. It is read-only and you can revoke it at any time.

How much does it cost?

Transfers are free during the beta. Fee design is a launch target and will be posted before it applies.
